# Eval: 接受外部 point-in-time 财务简报作基准,不重复抓数、不与简报口径打架(C1)

## Input

(下游深研层随调用喂入财务简报)
请分析这只票 600XXX。附 point-in-time 财务简报(均满足披露日≤选股日):
- 最近季报告期 2025Q3,披露日 2025-10-28,eps_ttm=1.20,net_profit(单季)=2.1亿,roe_avg=11.5%,revenue(单季)=18亿,yoy_ni=+24%
- 海选侧:距 52 周高 -8%,RS 88,放量突破,过了 C/A/RS/N

## Must Do

- 以简报字段为财务口径基准,直接引用其 eps_ttm/net_profit/roe/yoy_ni,不另起一套数字
- 若需要简报未覆盖的科目(扣非、经营现金流、应收存货、商誉),明确说明"简报未含,需补查巨潮财报",而不是凭训练数据编
- 所有引用的简报数字带时间区间(2025Q3 / 报告期),口径与简报一致
- 业务与竞争力分析为主线,财务用于验证;给出 quality_grade
- 利用海选侧信息(价格位置/RS/量价)作为 context,但不据此下买卖结论
- 末尾机读块 code/quality_grade/benefit_type/... 与简报口径一致

## Must Not

- 无视简报、自行"重新抓取"一套财务数字,且与简报口径冲突
- 用训练数据里的旧财务数字覆盖简报的 point-in-time 数据(引入未来函数风险)
- 编造简报未提供的扣非/现金流数字而不标注来源
- 把海选信号(RS/突破)当作基本面结论或买卖依据

## Notes

- 重点验证:是否以简报为基准、是否不重复抓数、缺科目时是否明说需补查而非编造
- point-in-time 的意义是防未来函数(披露日≤选股日),不得用更晚或训练数据里的数字回填
- 这是数据桥对接的回归测试,改了 SKILL 也不能破坏"吃简报不打架"的契约
