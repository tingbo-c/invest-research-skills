# Stock Fundamental Analysis Skill(个股基本面)

面向 A股个股深度基本面分析的 skill。目标不是套一套财务筛选器,而是先研究业务与竞争力,再用财务验证。
支持被下游「深研层」批量编排:接受外部 point-in-time 财务简报作为输入基准,单只可独立调用,输出含机读标签的深研卡片。

## 适用场景

- 分析某只股票的业务模式、产业链位置、客户与供应商结构
- 判断公司有没有议价权、核心能力或更可持续的竞争优势
- 看公司与主要竞争对手的差异
- 验证财务质量、利润真实性与现金流,甄别业绩质量(真增长 / 存疑 / 疑粉饰)
- 涉及题材/产业链时,嵌入式调用题材链分析,判断受益类型与题材阶段
- 在用户明确要求时,补充筛选、估值或投资结论

## 不适用场景

- 单独研究行业、赛道、市场规模或竞争格局:用 `sector-research`
- 产业链动态(瓶颈/受益归属/价值迁移):用 `theme-chain-context`
- 审查已有研究内容的逻辑与披露质量:用 `research-review`
- 若宏观变量会显著改变公司结论,应在当前分析中显式补上宏观变量与传导链

## 推荐分析顺序

1. 公司做什么,收入和利润分别来自哪里
2. 公司在产业链哪一环赚钱,客户是谁,供应商是谁
3. 公司真正的核心能力是什么,为什么客户会选择它
4. 主要竞争对手是谁,公司相对强弱在哪
5. 行业与题材趋势如何传导到收入、利润和份额(嵌入式调用题材链)
6. 财务验证前面的业务判断 + 业绩质量甄别
7. 什么信号会推翻当前结论

## 方法特点

- 先业务、后财务:先解释公司为什么能赚钱,再看报表是否支撑
- 主问题驱动:正文围绕 1-3 个关键矛盾展开,不做填表式平行铺陈
- 不要求每家公司都写成核心技术型,而是分析其真正的核心能力
- 风险部分不写空话,只写关键反证信号 + 可跟踪指标
- 与 `sector-research`、`theme-chain-context`、`research-review` 明确分工
- 输出含机读块,供下游深研卡片回填(quality_grade / benefit_type / theme_stage)
