# 财务质量、利润真实性与业绩质量甄别

本文件用于验证前文业务判断是否成立,并对业绩质量做结构化甄别。不是把个股分析做成机械阈值检查。

## 使用前提

- 默认至少读取三表、MD&A(管理层讨论与分析)和与异常项目直接相关的附注;A股一手来源为巨潮/交易所披露的定期报告。
- **若下游已提供 point-in-time 财务简报(见 SKILL.md「输入契约」),以简报为口径基准,不重复抓数、不与简报口径打架**;简报未覆盖的科目(如非经常性损益、现金流、应收存货)再补查财报。
- 若既无财报也无可靠财务简报,不得声称完成了利润质量判断。

## 核心任务

至少回答四件事:

1. 收入和利润变化能否用业务逻辑解释
2. 利润是否有真实现金支撑
3. 当前财务压力来自扩张、周期,还是经营恶化
4. 报表利润里有多少部分真实、多少虚弱

---

## 第一层:先看趋势,不看单点

至少结合近 3-5 年观察:

- 收入增速
- 毛利率、净利率
- 期间费用率
- 经营现金流
- 应收、存货周转、资产负债率

如果单年/单季变化很大,先解释变化原因,再下结论。**单期同比尤其要警惕基数效应(见下「业绩质量甄别」)。**

## 第二层:检查利润是否主要来自经营

重点排查这些项目是否显著影响利润(即 A股「非经常性损益」):

- 政府补助
- 价格/公允价值变动损益
- 投资收益(含处置子公司/参股收益)
- 资产处置收益
- 汇兑损益
- 债务重组、税收返还等其他一次性项

输出时回答:

- 哪部分利润更接近真实经营利润(对应**扣非净利润**)
- 哪部分利润更多是一次性、非经营性或偏虚
- **扣非净利润与净利润背离大** = 利润质量存疑信号

## 第三层:检查利润与现金是否匹配

重点看:

- 净利润与经营现金流是否匹配
- 应收增速是否快于收入增速
- 存货增速是否快于收入增速
- 合同负债/预收、应付是否支持当前收入质量

常见解释方向:

- 利润高、现金弱:应收拉长 / 库存堆积 / 渠道压货 / 回款转差
- 利润弱、现金不弱:去库存 / 预收增加 / 费用前置 / 资本开支节奏

## 第四层:区分扩张投入和经营恶化

若现金流较弱,不要直接下坏结论,先回答:

- 当前资本开支偏维护还是扩张
- 新增投入有没有订单/收入/产能爬坡或门店模型验证
- 现金流压力是扩张结果,还是商业模式本身的问题

## 第五层:做简化会计还原

这里的「还原」不是重编报表,而是研究员层面的质量判断:

- 剔除明显的一次性和非经营性收益
- 注意研发费用资本化、折旧摊销政策、商誉与无形资产对利润可比性的影响
- 区分维护性投入与扩张性投入
- 判断当前利润质量是改善、稳定还是恶化

## 业绩质量甄别(C2,结构化,产出 quality_grade)⭐

> **为什么单列**:下游海选会按量化指标(如净利同比 yoy_ni)筛出候选,其中混有「低基数假象」「一次性粉饰」的伪增长。本节负责把它们甄别出来,产出机读标签 `quality_grade`,回填深研卡片。
> **口径基准**:优先用下游简报的 point-in-time 字段(eps_ttm、net_profit 绝对值、roe_avg、revenue、yoy_ni 跨 29 季度),不足再补财报。

四个甄别维度,逐一打 flag:

### 1. 低基数假象 flag

同比增速极高,但要看绝对值与基数:

- **净利润绝对值很小**(yoy_ni 高达数百倍/数万倍,但 net_profit 绝对额极小)→ 低基数,增速无意义
- **扭亏为盈/微利**(上年同期亏损或接近 0)→ 同比百分比失真
- **连亏多季后单季转正** → 可能是一次性,不是趋势

> 示例:某票 EPS 同比 +68902%,但净利润绝对值很小、ROE 为负、连亏多季 → 判「**低基数假象**」,不是真增长。

### 2. 非经常损益 flag(扣非背离)

- 扣非净利润 << 净利润 → 利润靠非经常性损益撑(政府补助/投资收益/资产处置)
- 扣非净利润为负但净利润为正 → 主业实际亏损,报表盈利是「修饰」
- 看非经常性损益占净利润比重,>30% 即需显著提示

### 3. ROE 背离 flag

- 利润同比高增,但 roe_avg 仍很低或为负 → 盈利能力未真实改善(低基数/摊薄/资产臃肿)
- ROE 高但靠高杠杆(资产负债率高企)而非经营效率 → 质量打折
- ROE 由减值后净资产缩水被动抬高 → 假改善

### 4. 现金流不匹配 flag

- 净利润为正但经营现金流持续为负/远低于净利润 → 利润不落地
- 收现比、净现比持续低位 → 利润含金量低
- 应收/存货增速持续快于收入 → 利润前置、回款堪忧

### quality_grade 判定规则

| 等级 | 条件 |
|---|---|
| **真增长** | 四个 flag 基本不触发:绝对额有意义、扣非与净利接近、ROE 真实改善、现金流匹配 |
| **存疑** | 触发 1-2 个 flag,或增长依赖单一非经常因素但主业未恶化 |
| **疑粉饰** | 触发 ≥3 个 flag,或低基数+扣非为负+现金流背离同时出现 |

无法判断(数据不足)时填 `未知`,不编造。

## 第六层:领先信号识别(炒预期的财务线索)

> **核心逻辑**:股价炒的是预期差,财务里有些指标领先于利润表现,能在市场定价之前捕捉业务拐点。本层专门识别这类信号。

### 订单/需求端（最领先）

- **合同负债 / 预收账款增加** → 未来收入已锁定,利润表还没体现
- **在手订单增长**（工程机械、军工、设备类披露）→ 未来收入能见度高
- **经销商打款 / 渠道预付**增加 → 消费品需求预期升温

⚠️ A股坑:合同负债增加有时是**渠道压货**而非真实需求,需结合终端动销数据交叉验证。

### 产能/资本投入端

- **资本开支突然放量** → 管理层内部判断需求将起,领先市场 6-18 个月;但要区分主动扩产 vs 政府撮合项目
- **员工人数/招聘方向变化** → 扩招研发意味产品迭代提速;扩招销售意味放量信心
- **原材料采购 / 存货前置** → 备货行为本身是需求预期的信号

### 利润率拐点信号

- **毛利率触底回升**（周期行业尤其有效,比净利润早 1-2 个季度）
- **费用率见顶回落**（销售费用率 / 管理费用率开始收缩）→ 规模效应开始显现
- **扣非净利润增速 > 净利润增速** → 主业质量改善,不只是一次性

### 现金流领先于利润

- **经营现金流 > 净利润**开始出现 → 应收账款在收回,利润含金量升
- **自由现金流由负转正** → 重资产扩张期结束,进入现金收获期
- **收现比、净现比回升** → 回款改善先于利润改善

### 管理层行为信号（最难伪造）

- **真实回购**（实际注销,非只公告）→ 内部对估值低估有判断
- **大股东低位增持**（尤其非质押套现背景下）
- **分红率提升 / 特别分红** → 内部确认现金流稳定可持续

### 行业特化

| 行业类型 | 重点领先指标 |
|---|---|
| 周期（化工/钢铁/有色）| 产品价格/库存周期 + 毛利率拐点 |
| 科技/成长 | 研发费用率走势 + 合同负债 + 大客户集中度变化 |
| 消费/品牌 | 经销商打款 + 存货周转 + 新开店/关店速度 |
| 重资产/基建 | 资本开支性质(扩张 vs 维护)+ 在手订单 |
| 金融 | 不适用上述逻辑,看拨备前利润 / 净息差 / 不良率拐点 |

### 输出要求

识别到领先信号时,在人读部分补充说明:
- 信号类型（订单/产能/利润率/现金流/管理层行为）
- 信号强度（单一信号 / 多信号共振）
- 可能的领先周期（几个季度后利润表可能体现）
- A股坑提示（该信号在 A股 是否存在失真风险）

## 异常项追问清单

出现以下情形时,必须追问原因:

- 收入增长,但毛利率持续下滑
- 净利润增长,但经营现金流明显跟不上
- 应收或存货显著快于收入增长
- 资本开支大幅抬升,但收入和利润没有验证
- 商誉、合同资产、其他应收款明显增加
- 财务费用/有息负债快速上升
- 频繁更换会计师事务所或审计意见非标

---

## 输出要求

输出时至少写清:

1. 财务支持前文业务判断的证据是什么
2. 财务削弱前文业务判断的证据是什么
3. 当前利润质量与现金含量处于改善、稳定还是恶化
4. **业绩质量评级(quality_grade)+ 触发的 flag 依据**

末尾机读字段(并入个股报告的机读块):

```yaml
financial_quality:
  quality_grade: 真增长 | 存疑 | 疑粉饰 | 未知
  flags:
    low_base: true | false        # 低基数假象
    non_recurring: true | false   # 扣非背离
    roe_divergence: true | false  # ROE 背离
    cashflow_mismatch: true | false  # 现金流不匹配
  note: <一句话依据>
```

## 一句话原则

财务分析的目的不是证明公司指标好看,而是判断报表是否真的支撑前文的业务与竞争力结论;**对海选喂来的高增长候选,先问一句「这是真增长还是低基数假象」。**
