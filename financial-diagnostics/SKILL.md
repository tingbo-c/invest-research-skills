# A股财务质量深诊

> **定位**:验证业务判断是否有财务支撑,并识别领先于利润表的预期信号。不是机械阈值打分,而是研究员视角的结构化甄别。
> **调用方**:通常由 `stock-fundamental` 在 C2 阶段嵌入调用;也可独立触发(单独分析一只票的财务质量)。

---

## 输入契约

**优先**:下游提供的 point-in-time 财务简报(来自 DuckDB):
- `code` / `name`
- 29 季度的 `stat_date`(报告期)、`pub_date`(披露日)
- `eps_ttm`、`net_profit`(绝对值)、`roe_avg`、`revenue`、`yoy_ni`
- 满足「披露日 ≤ 选股日」防未来函数

**补充**:简报未覆盖的科目(非经常性损益、现金流、应收存货)→ 巨潮/交易所定期报告附注。

**底线**:既无财报也无可靠简报 → 不得声称完成财务质量判断,填 `未知`。

---

## 分析框架(六层)

### 第一层:先看趋势,不看单点

至少结合近 3-5 年(或 29 季度简报)观察:
- 收入增速、毛利率、净利率
- 期间费用率
- 经营现金流
- 应收/存货周转、资产负债率

单年/单季变化大 → 先解释原因,再下结论。**警惕基数效应。**

### 第二层:利润来源检查(非经常性损益)

排查是否显著影响利润:政府补助、公允价值变动、投资收益、资产处置、汇兑、债务重组、税收返还。

输出:哪部分接近真实经营利润(扣非净利润)?哪部分偏一次性?**扣非与净利背离大 = 存疑信号。**

### 第三层:利润与现金匹配

- 净利润 vs 经营现金流
- 应收/存货增速 vs 收入增速
- 合同负债/预收、应付是否支持收入质量

常见解释:利润高现金弱(应收拉长/渠道压货) vs 利润弱现金不弱(去库存/费用前置)。

### 第四层:扩张投入 vs 经营恶化

现金流弱时,先判断:
- 资本开支性质(维护 vs 扩张)
- 新增投入有无订单/收入/产能爬坡验证
- 现金压力是扩张副产品,还是商业模式问题

### 第五层:简化会计还原

- 剔除明显一次性和非经营收益
- 注意研发费用资本化、折旧摊销政策对可比性的影响
- 区分维护性投入与扩张性投入
- 判断利润质量趋势:改善 / 稳定 / 恶化

### 第六层:领先信号识别(炒预期的财务线索)

> 股价炒预期差——这些指标领先于利润表,能在市场定价前捕捉拐点。

**订单/需求端(最领先)**
- 合同负债/预收增加 → 未来收入已锁定
- 在手订单增长(工程机械/军工/设备类)
- 经销商打款/渠道预付增加(消费品)
- ⚠️ A股坑:合同负债增加可能是渠道压货,需交叉验证终端动销

**产能/资本投入端**
- 资本开支突然放量 → 管理层预判需求将起(领先 6-18 个月);区分主动扩产 vs 政府撮合
- 员工人数/招聘方向变化
- 原材料采购/存货前置

**利润率拐点信号**
- 毛利率触底回升(周期行业比净利润早 1-2 季度)
- 费用率见顶回落 → 规模效应显现
- 扣非净利润增速 > 净利润增速 → 主业质量改善

**现金流领先于利润**
- 经营现金流 > 净利润开始出现 → 应收在收回
- 自由现金流由负转正 → 进入现金收获期
- 收现比/净现比回升

**管理层行为(最难伪造)**
- 真实回购(实际注销)
- 大股东低位增持(非质押套现背景)
- 分红率提升/特别分红

**行业特化**

| 行业类型 | 重点领先指标 |
|---|---|
| 周期(化工/钢铁/有色) | 产品价格/库存周期 + 毛利率拐点 |
| 科技/成长 | 研发费用率走势 + 合同负债 + 大客户集中度变化 |
| 消费/品牌 | 经销商打款 + 存货周转 + 新开店/关店速度 |
| 重资产/基建 | 资本开支性质(扩张 vs 维护)+ 在手订单 |
| 金融 | 不适用三表逻辑,看拨备前利润/净息差/不良率拐点 |

## 业绩质量甄别(C2,产出 quality_grade)

> 海选按量化指标筛出候选,其中混有「低基数假象」「一次性粉饰」的伪增长。本节负责甄别。

四个 flag 逐一判断:

**1. 低基数假象**
- yoy_ni 极高但 net_profit 绝对值极小 → 增速无意义
- 扭亏为盈/微利 → 同比百分比失真
- 连亏多季后单季转正 → 可能一次性

**2. 非经常损益(扣非背离)**
- 扣非净利润 << 净利润 → 利润靠非经常撑
- 扣非为负但净利为正 → 主业实际亏损
- 非经常占净利润 >30% → 显著提示

**3. ROE 背离**
- 利润高增但 roe_avg 仍低/为负 → 盈利能力未真实改善
- ROE 高但靠高杠杆而非经营效率
- ROE 由减值后净资产缩水被动抬高

**4. 现金流不匹配**
- 净利润正但经营现金流持续为负/远低
- 收现比/净现比持续低位
- 应收/存货增速持续快于收入

**quality_grade 判定**

| 等级 | 条件 |
|---|---|
| 真增长 | 四个 flag 基本不触发 |
| 存疑 | 触发 1-2 个 flag,或依赖单一非经常因素但主业未恶化 |
| 疑粉饰 | 触发 ≥3 个 flag,或低基数+扣非为负+现金流背离同时出现 |

数据不足 → 填 `未知`,不编造。

## 异常项追问清单

出现以下情形必须追问原因:
- 收入增长但毛利率持续下滑
- 净利润增长但经营现金流明显跟不上
- 应收或存货显著快于收入增长
- 资本开支大幅抬升但收入利润没有验证
- 商誉、合同资产、其他应收款明显增加
- 财务费用/有息负债快速上升
- 频繁更换会计师或审计意见非标

---

## 输出要求

人读部分至少写清:
1. 财务支持前文业务判断的证据
2. 财务削弱前文业务判断的证据
3. 当前利润质量趋势(改善/稳定/恶化)
4. quality_grade + 触发 flag 依据
5. 领先信号识别结果(类型/强度/领先周期/A股坑提示)

末尾机读块并入深研卡片:

```yaml
financial_quality:
  quality_grade: 真增长 | 存疑 | 疑粉饰 | 未知
  flags:
    low_base: true | false
    non_recurring: true | false
    roe_divergence: true | false
    cashflow_mismatch: true | false
  leading_signals:
    types: [订单, 产能, 利润率拐点, 现金流, 管理层行为]   # 命中的类型,可多选,无则为空列表
    strength: 单一信号 | 多信号共振 | 无 | 未知
    lead_quarters: <预估领先季度数,如 2-4,无则空>
  note: <一句话依据>
```

---

## 一句话原则

财务分析的目的不是证明指标好看,而是判断报表是否真的支撑业务与竞争力结论。**对高增长候选,先问:这是真增长还是低基数假象?有没有领先信号指向未来拐点?**
