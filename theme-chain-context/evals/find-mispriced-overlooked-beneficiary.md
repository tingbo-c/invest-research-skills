# Eval: 受益者题必须挖"被错杀"(预期差最高一类),不能只答直接受益

## Input

AI 算力这条链上,市场目前主要在炒光模块和液冷的几个龙头。这条链上有没有被市场以为受损或中性、其实是受益的环节?

## Must Do

- 明确回答"被错杀"类:市场以为受损/中性、实际真受益但尚未充分定价的环节或公司(公司名 + 6 位代码)
- 对每个"被错杀"标的,说明:市场为什么误判、有什么数据点证明它其实受益(ASP 上升/订单/份额变化)
- 同时给出当前直接受益与间接受益,避免遗漏 context
- WebSearch 接入最近 3-6 个月数据支撑"被错杀"的判断(不能只凭训练数据推理)
- 给题材阶段与拥挤度判断:市场已扎堆的光模块/液冷处于什么阶段、被错杀环节是否还在早期
- 末尾机读块给出 benefit_type=被错杀 的标的及其 sources

## Must Not

- 只答直接受益(光模块/液冷),跳过被错杀类
- "被错杀"判断没有数据点支撑,纯主观推理
- 把已经被市场充分炒作的龙头说成"被错杀"
- 不做 WebSearch,用训练数据下的旧格局判断"当前谁被错杀"
- 输出买卖/仓位建议

## Notes

- 重点验证:是否真的挖出被错杀类并给数据点、是否区分"已拥挤的直接受益 vs 仍在早期的被错杀"
- 被错杀是 alpha 最高的一类,也是深研最有价值的输出;若 WebSearch 后确无被错杀环节,需明说"未发现明显被错杀",不可硬编
- 不要求预测涨跌,只要求把预期差所在讲清并可溯源
