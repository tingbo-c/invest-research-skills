# Eval: 独立题材链分析必须答动态瓶颈与迁移方向,而非静态罗列

## Input

帮我分析一下固态电池产业链现在的瓶颈在哪个环节。

## Must Do

- 答题 1(瓶颈题)必须是动态的:当前瓶颈环 + 半年前瓶颈环对比 + 迁移方向/速度
- 答题 2(机制题)给出瓶颈性质:技术性 / 产能性 / 商业性 / 政策性,并说明这决定 thesis 持续多久
- 用 WebSearch 接入最近 3-6 个月事件(量产工艺进展、扩产/中试线公告、车企装车 timeline、材料国产化进度)
- 关键趋势性结论带引用(URL + 日期),来源优先一手(业绩说明会/调研纪要/巨潮公告)
- 给出价值迁移判断:利润未来 1-2 年可能从哪一环迁向哪一环
- 给反证题:具体 data point + 观察窗口

## Must Not

- 只罗列产业链节点(正极/负极/电解质/设备…)和代表公司,不答瓶颈动态
- "瓶颈是 X"但不判断性质(技术性/产能性/政策性)
- 反证条件写"技术路线变化""竞争加剧"等空泛表述
- 全篇没有 6 个月内的数据或事件
- 6 题糊在叙事里,不显式标号

## Notes

- 重点验证:瓶颈是否动态(有半年前对比+迁移方向)、性质是否判断、是否 WebSearch 带 URL+日期
- 固态电池兼具技术性(工艺良率)与政策性(补贴/装车考核)瓶颈,允许混合性质但要拆分主次
- 不要求预测谁会赢,只要求把瓶颈动态与利润迁移方向讲清
