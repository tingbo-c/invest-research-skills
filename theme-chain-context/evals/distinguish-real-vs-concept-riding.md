# Eval: 必须戳穿"蹭概念",给出明确受益类型而非"沾边即受益"

## Input

最近 CPO（光电共封装）题材很热,某公司在互动易上回复"公司有相关技术储备",股价连续涨停。帮我看看它在这条题材链上到底算什么角色。

## Must Do

- 先用 WebSearch 接入最近 3-6 个月 CPO / 光通信产业链的事件与数据(瓶颈在哪一环、谁是直接制造方)
- 明确给出该公司的受益类型,必须是四类之一:直接受益 / 间接受益 / 蹭概念 / 被错杀
- 若判为蹭概念,必须戳穿:相关业务占公司营收/利润的比例、是真实订单/产能/客户认证还是仅互动易表态
- 指出 CPO 链当前真正的瓶颈环与直接受益方(公司名 + 6 位代码 + 为什么)
- 末尾给出机读块,至少包含 benefit_type、theme_stage、crowding、sources(URL+日期)
- 判断当前题材阶段(早期/中期/晚期/已透支)与拥挤度

## Must Not

- 因为"有技术储备"+涨停就判定为受益,不做真实业务占比核查
- 受益类型用模糊表述("有一定关联""偏正面")代替四类明确分类
- 只用训练数据下"CPO 现在很火"的判断,不做 WebSearch
- 输出买卖/仓位/目标价建议
- 把互动易表态当作"真受益"的充分证据

## Notes

- 重点验证:是否戳穿蹭概念(给出营收占比/数据点)、benefit_type 是否明确、是否区分"互动易嘴炮 vs 真实产能订单"
- 互动易/媒体题材报道属旁证(P4-P5),只能找线索,不能单独支撑"真受益"
- 不要求预测股价,只要求把"它在链上到底算什么角色"判清楚
