# A股题材链分析

> **核心目标**:输出 mechanism-level（机制级）趋势推论,不是节点罗列 + 八股填空。
> 利用 AI 训练数据 + WebSearch 现场调研,回答「哪一环正在变成新瓶颈、谁真受益、谁在蹭概念、题材炒到哪一步了、什么会推翻判断」。
> **专治 A股痛点**:题材炒作时,真受益 / 间接受益 / 蹭概念会被同一波情绪一起拉起来——本 skill 负责把它们拆开。

**最高纲领**(必读):[chain-analysis-framework.md](references/chain-analysis-framework.md)（6 题方法论 + WebSearch 规则 + 机读输出块）

---

## 两种触发模式

| 模式 | 触发 | 输出形态 |
|---|---|---|
| **A. 嵌入式（自动）** | stock-fundamental 分析产业链/题材相关个股时自动调用 | 融入个股报告的"题材链 context"段（默认简化档）+ 机读标签 |
| **B. 独立式（主动）** | 用户说「分析 X 题材链」/「X 现在瓶颈在哪」/「X 谁真受益」/「画一下 Y 产业链」 | 独立题材链报告（按用户档位） |

A + B 共用 `references/chain-analysis-framework.md` 方法论。
A 模式针对单只个股,核心交付 `benefit_type / theme_stage / crowding` 三个机读标签,回填深研卡片。

## 工作流

### 第一步:识别链边界

- 用户问哪条题材链?拓扑包含哪些环?
- 哪些是核心环,哪些是辅助环?
- 链的上游 / 下游边界在哪?
- A股口径:标的用 6 位代码;公司一手信息看交易所公告/巨潮、业绩说明会、调研纪要、互动易。

### 第二步:选档（深度）

| 触发词 | 档位 |
|---|---|
| "简化 / 概要 / 简单看一下 / 简单画一下" | 简化档 |
| 默认（不指定） | 默认档 |
| "详细 / 深度 / 完整画一下 / 量化利润迁移" | 深度档 |

A 模式默认简化档;用户明示升档才用深度档。

### 第三步:答 6 个推论题

参见 [chain-analysis-framework.md](references/chain-analysis-framework.md):

1. **瓶颈题**（动态:当前 vs 半年前 + 迁移方向）
2. **机制题**（性质:技术性 / 产能性 / 商业性 / **政策性**）
3. **受益者题**（直接 / 间接 / **蹭概念** / **被错杀**）⭐
4. **价值迁移题**（利润 1-2 年内迁向哪,深度档必答）
5. **反证题**（具体 data point + 观察窗口）
6. **题材阶段 / 拥挤度**（早期/中期/晚期/已透支 + 低/中/高）⭐ A股专属

### 第四步:WebSearch 强制接入

- 推论题 1 / 2 / 4 / 5 及第 6 维 **必须**有最近 3-6 个月事件 / 数据支持
- 引用必须带 **URL + 日期**
- 不允许只用训练数据 cutoff 内的判断下"当前 / 现在"类结论
- WebSearch 不可用时降级（明确标注,不输出趋势性结论）

### 第五步:输出 + 机读标签

- 人读部分:先结论后依据,6 题显式标号
- 末尾附 `yaml` 机读块（见 framework 末尾"机读输出块"）:嵌入式调用时 `benefit_type / theme_stage / crowding` 必须给值,无法判断填 `未知`,不编造。

## Hard Rules

- ❌ 不预存任何题材百科文件（不写 算力链.md / 固态电池链.md 等）,全部现场 WebSearch 生成
- ❌ 不允许节点罗列代替机制推论
- ❌ 不允许只用训练数据 cutoff 内事件下"当前 / 现在"类结论
- ❌ 不允许"沾边就受益"——蹭概念必须戳穿（给营收占比 + 数据点）
- ❌ 不允许反证条件写"行业风险""竞争加剧"等空泛
- ✅ 6 题答案必须显式标注章节（不能糊在叙事里）
- ✅ WebSearch 引用必须带 URL + 日期
- ✅ 第 6 维（题材阶段/拥挤度）A股必答,直接产出卡片标签
- ✅ 被错杀类别是 alpha 核心,不能跳过
- ✅ 深度档触发模糊时主动反问
- ✅ 只分析不建议:不出仓位 / 目标价 / 买卖时机

---

## 输出原则

- 不强制固定段落数 / 章节结构,但 6 题是 hard requirement（简化档下题 4 可跳过）
- A 模式输出简洁（默认 ≤ 300 字）+ 末尾机读块
- B 模式按用户档位伸缩
- 数据必有时间 + 来源（URL + 日期）
- A股数据来源优先级:交易所公告/巨潮 > 业绩说明会/调研纪要/互动易 > 行业协会/统计局 > 券商研报/媒体;互动易与媒体题材报道为旁证(P4-P5),不单独支撑"真受益"结论
