# 认知博弈框架(信息差 / 逻辑差 / 预期差 / 催化剂)

> **用途**:个股 alpha 来自"我和市场共识的差异在哪"。任何带投资判断倾向的分析,显式过四层博弈差 + 催化剂。
> **诚实层**:任何一层不存在时必须明说"无此层",**严禁制造虚假博弈差**——把共识包装成"信息差"、把基本面观察包装成"逻辑差",是最常见的失败模式。
> **合成规则**:≥2 层博弈差 + 1 个明确催化剂 = 真实 differential 成立;否则只是完整研究,不构成差异化判断。
>
> ⚠️ 本文档不是 checklist:每层举例只是让你理解"长什么样",真实 edge 多在举例之外。带着具体公司具体问题自由识别,不要按表格穷举。

---

## 一、信息差

**我看到了市场没充分消化的公开信息**(不是内幕信息)。

### 启发性举例(A股,非穷举)
- 定期报告埋藏的细节(年报附注分部数据、季报里的合同负债/存货结构、募投项目进度、关联交易变化)
- 业绩说明会/调研纪要里的措辞演化(管理层语气、对某业务的回避或强调)
- 跨公司交叉(上游公司订单/排产暗示下游真实需求;客户年报里对供应商的描述)
- 行业数据未被映射到个股(行业协会月度产量/价格存在,但未连接到具体公司份额)
- 二阶信息(董监高增减持时点、股权激励行权条件隐含的业绩底、供应链/招投标数据)

### 质量检验(必答)
- 具体是什么事实?在哪里可验证(公告/文件 + 日期 + 出处)?
- 为什么市场没反应?(技术性 / 时间滞后 / 注意力不对称 / 信号埋藏)

### 反例
- ❌ "市场低估了这家公司"——观点,非事实
- ❌ "AI/新能源趋势利好"——共识叙事
- ❌ 已出现在券商首推研报头版——已是共识

## 二、逻辑差

**同样的公开信息,我推理出共识没推出的结论**。

### 启发性举例(A股,非穷举)
- 跨周期类比(本轮产能周期类比上一轮的出清节奏)
- 多公司交叉验证(上游材料 + 中游设备 + 下游需求三方反推某家真实增速)
- 因果链推演(集采降价 → 行业出清 → 龙头份额提升 → 单位盈利触底回升)
- 价值链联动(上游瓶颈缓解 → 中游某家率先毛利扩张)
- 时间维度错配(共识看一年,我看 3-5 年产能/份额格局)

### 质量检验(必答)
- 推理链每一步 + 数据支撑?
- 共识的推理在哪一步不同?
- **可证伪信号**:什么数据会推翻这个推理?

### 反例
- ❌ "我觉得被低估"——无推理链
- ❌ "管理层有远见"——主观评价
- ❌ 推理无法被反驳——这是叙事不是逻辑

---

## 三、预期差

**我的预期与当前股价隐含预期的量化差距**。

### 市场预期的测量方式
- 反推估值(当前股价/市值隐含的增速、净利率、份额假设——把它算出来)
- 卖方一致预期(Wind/同花顺/choice consensus)
- 管理层指引 / 股权激励业绩条件
- 历史估值分位(当前 PE/PB 在自身和同业历史的分位)

### Gap 形式举例(非穷举)
利润率 gap / 收入 gap / 估值倍数 gap / 久期 gap(短期 vs 长期)/ 结构 gap

### 质量检验(必答)
- 当前股价隐含什么具体数字?(必须算出来)
- 我的预期是什么数字?
- Gap 在什么时间维度上存在?
- Gap 挂钩到哪个信息差 / 逻辑差?

### 反例
- ❌ "估值便宜"——无量化
- ❌ "成长股值高估值"——叙事,非 gap

## 四、催化剂

**让预期差被市场识别和定价的具体事件**。没有催化剂 = 价值陷阱风险(便宜可永远便宜)。

### 常见形式(A股,非穷举)
- 时间确定:定期报告/业绩预告、解禁、指数纳入、集采/招标开标、产品发布、限售到期
- 事件确定时间不确定:重组/并购过会、实控人变更、监管决定、大额订单落地
- 路径确定终点不确定:多季度业绩序列逐步验证(复合催化)

### 质量检验(必答)
- 具体事件 + 时间窗口?
- 为什么*会*而不是*可能*触发重定价?
- 当前是否已被 priced in(结合 event-interpretation 的 Priced-in 检验)?

### 反例
- ❌ "当市场意识到……"——一厢情愿
- ❌ "估值终将回归"——无时间窗口

**无催化剂时**:输出"研究完成,无明确催化剂——预期差可能长期不被定价"。

---

## 五、完整性合成判断(不是 actionable 信号)

这是分析完整性自检——告诉你这份研究"有多少 differential",不是告诉用户买卖。

```
差异强度 = ≥2 层博弈差 + 1 个明确催化剂
```

| 组合 | 分析判断 |
|---|---|
| 4 层 + 催化剂 | 与共识 differential 极强,兑现路径清晰 |
| 2-3 层 + 催化剂 | 有 differential,需观察催化剂兑现 |
| ≥2 层 + 无催化剂 | 有 differential 但可能长期不被定价 |
| 仅 1 层 | differential 薄弱 |
| 0 层 | "本研究构成完整基本面分析,但未识别出与共识的关键差异" |

**诚实原则(hard rule)**:4 层全无时,输出"未识别 differential"是合法且诚实的——比制造假 differential 更有价值。

---

## 七、Hard Rules

- 必须显式过 4 层 + 合成判定
- 任一层不存在必须明说"无此层"
- 严禁制造虚假博弈差(共识当信息差、观察当逻辑差)
- 4 层全无 → 输出"未识别 differential",仍是合法输出
- 启发性举例不是 checklist,不按表格逐一查
- 只分析不建议:differential 再强也不输出仓位/目标价/买卖
