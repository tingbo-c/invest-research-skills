# 数据来源分级 + 快照数据规则

> **核心原则**:framework 最大的潜在 bug 不是分析不够聪明,而是**模型把半可靠数据写得很确定**、或**用过时的训练数据冒充当前数字**。本文件强制所有数据标注**来源 + 日期 + 口径**,并硬化实时数据的取数纪律。
> 本文件与 [data-quality-levels.md](data-quality-levels.md) 的 P1-P5 配套使用:P1-P5 定"这个数字有多硬",本文件定"A股具体哪类来源算哪级 + 实时数据怎么取"。

---

## 一、A股来源 → P1-P5 映射

| 级别 | 来源类型 | A股具体来源 | 允许用于 |
|---|---|---|---|
| **P1** | 官方一手 | 巨潮/交易所公告(年报/季报/招股书/业绩预告快报/重大合同/权益变动/问询函回复)、证监会、统计局、海关、央行、各部委政策、集采/招标官方结果 | 核心财务数字、披露事实、政策约束 |
| **P2** | 协会与原始经营披露 | 行业协会数据、上市公司定期报告拆解、业绩说明会/调研纪要 | 细分赛道、产业链验证、竞争格局 |
| **P3** | 可交叉验证的交易/业务数据 | 招投标、海关 HS 细项、价格/库存/开工率、月度产销、门店/渠道数据 | 验证景气、订单、价格、库存、项目落地 |
| **P4** | 第三方研究与数据库 | 券商研报、咨询公司、Wind/同花顺/choice/东财等数据库、财联社/证券时报报道 | 补方法/口径/框架,不单独作主证据 |
| **P5** | 另类与行为数据 | 股吧/雪球舆情、互动易未证实表态、小作文、搜索指数、App 活跃 | 只找线索/验证方向,不单独支撑结论 |

> 互动易官方回复介于 P2-P4:涉及具体经营数据时近 P2,但口头表态、未落公告的"意向"按 P4-P5,且 A股小作文盛行,传闻一律 P5。

---

## 二、按数据类型匹配最低级别

| 数据类型 | 必须 ≥ |
|---|---|
| 收入/净利润/扣非/EPS/现金流(历史已披露) | **P1**(直接引用定期报告) |
| 毛利率/费用率/资本开支(历史) | **P1** |
| 股价/市值/流通股本/换手率 | **P1(公告)或 P2/P4(行情数据源)+ as-of 日期** |
| PE/PB/估值分位 | **P4 数据库 + 来源日期** |
| 卖方一致预期 | **P4** |
| 行业市场规模/增速 | **P1(协会/监管)或 P4(数据库)+ 标注估算** |
| 政策/集采/招标事件 | **P1**(官方文件/开标结果) |
| 财报后市场反应 | **P4** 可,但标"市场观察非官方判断" |
| 传闻/小作文/未证实信息 | **P5**,不能进入核心结论 |

---

## 三、引用格式

每个核心数字标注 **来源 + 日期 + 口径**:

```
[P1] [数据] [来源 + 日期 + 口径]
```

**正确示例**:
- 「2025 全年归母净利 X 亿 [P1,某公司 2025 年报,2026-03-28 披露,CAS,归母]」
- 「PE(TTM) 约 35x [P4,同花顺,截至 2026-06-20]」
- 「某政策落地 [P1,某部委 2026-05-10 发文,URL]」

**错误示例**:无来源/无日期的"约 X 亿"、"市场认为高估"、"据报道……"。

---

## 四、快照数据强制规则(防训练数据过时)

涉及**实时变化数据**时,**不允许直接用训练数据里的数字**——训练 cutoff 可能落后数月,股价/市值/PE/换手会严重失真。

**快照数据类型**:当前股价/市值/流通股本、PE/PB/估值分位、换手率/成交、最新一期实际财务、当前一致预期。

**处理优先级**:

| 优先级 | 方法 | 标注 |
|---|---|---|
| 1. 优先 | 取数工具/行情接口 | `[P2/P4, 数据源, 2026-06-20 当日]` |
| 2. 次选 | WebSearch 检索最新 | `[来源 URL + 日期]` |
| 3. 降级 | 明示训练 cutoff + 警告 | `[训练 cutoff,请以现价为准]` + 改用反推估算 |

所有快照数据强制标 as-of 日期(精确到 YYYY-MM-DD);**严禁出现"未标注来源/日期的当前数字"**。

---

## 五、口径标注(三项)

| 口径 | 选项 |
|---|---|
| 会计准则 | CAS(中国准则)/ IFRS;归母 vs 全部;扣非 vs 未扣 |
| 时间口径 | 报告期 / TTM / 全年 / H1 / 单季;注意财报披露滞后 |
| 披露状态 | 披露 / 估算 / 推测 / 预测(consensus / 自己估) |

---

## 六、核心结论依赖低级别来源时的强制警告

当**核心结论的关键论据**依赖 P4(媒体/研报)或 P5(传闻)时,即使标了来源,仍需单独加警告:

```
⚠️ 该核心判断依赖 [P4/P5 具体来源],需等 [定期报告/公告/官方文件] 进一步验证。
在官方确认前,结论应视为"基于媒体/传闻线索的初步判断"。
```

原因:P4/P5 常滞后、转述失真、选择性报道;对抗审查的"事实是否硬"依赖来源等级,不能把 P4/P5 当 P1 用。

---

## 七、Hard Rules

- ❌ 核心数字无来源/无日期/无口径
- ❌ 用 P5(传闻/小作文)支撑核心结论
- ❌ 快照数据用训练 cutoff 内数字而不标注
- ❌ "据报道/据说/市场认为"等无来源表述
- ❌ 混用归母/全部、扣非/未扣不标
- ✅ 每个核心数字标 P 级 + 来源 + 日期 + 口径
- ✅ 快照数据三层 fallback(工具/WebSearch/cutoff),必标 as-of 日期
- ✅ 估算/推测/自算明示,不冒充披露
