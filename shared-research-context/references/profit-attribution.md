# 利润归属分析(rent 7 类截留)

> **条件强制**:分析产业链/题材受益者(任何"X 利好"叙事)时,必须问"利润(rent)归谁"——避免把**产业利好误当公司利好**。
> 不必按 7 类逐一打分,深挖最相关的 1-3 个截留维度即可。
> 与 `../../stock-fundamental/references/profit-transmission.md`(利润传导链)互补:传导链问"变量怎么传到利润表",本文件问"传到的利润最后被谁拿走"。

---

## 7 类 Rent 截留者(A股口径)

| 类型 | 机制 | 量化信号 |
|---|---|---|
| **1. 大客户截留** | 下游集中度高 + 买方议价权(果链对苹果、某车企对零部件、商超对食品供应商) | Top 1-3 客户 >30% 收入 / 毛利率低于行业且趋势压缩 / 被迫返利账期 |
| **2. 监管/政策截留** | 集采、医保控费、限价、电价管制、出口管制 | 政策已落地执行 / 历史同类政策的利润影响 / 公告风险提示列出 |
| **3. 长协/锁价截留** | 长期固定价合约锁死 rent(长协煤、锁价 PPA、长单代工) | 长协占收入比 / 长协价 vs 现货价差 / 到期换签节奏 |
| **4. 上游卡脖子截留** | 关键供应商集中或技术垄断(光刻机、先进制程代工、锂/稀土、关键 IP) | 上游集中度极高 / 上游毛利远高于下游 / 上游持续提价 |
| **5. 同业竞争流向下游/消费者** | 行业过度竞争,无人稳定截留(同质化制造、低端、价格战赛道) | 行业集中度低 / 行业毛利连续 3 年压缩 / 新进入者增多、扩产潮 |
| **6. Capex 再投入截留** | 利润必须持续再投资维持地位(重资产周期、扩产军备竞赛) | 资本开支/收入 >15-20% / 经营现金流转化净利 <60% / 资本开支/折旧长期 >1.5 |
| **7. 利息截留** | 高杠杆公司 rent 流向债权人 | 有息负债/EBITDA >4x / 利息保障倍数 <3x / 短债集中 |

---

## 综合判定:Rent capture %

```
公司 rent capture % = 100% − 各类截留之和
```

| Rent capture | 分析判断 |
|---|---|
| > 70% | 强——产业利好能落到公司净利上 |
| 50-70% | 中等——需结合其他因素 |
| 30-50% | 弱——产业利好大部分被截留,公司层面 alpha 有限 |
| < 30% | "被挤压者"——即使产业景气,公司实质受益有限 |

---

## 持续性判断

仅当前 rent capture 高还不够,必须看持续性:

**强(rent 稳定)**:护城河来自网络效应/转换成本/牌照壁垒;上下游集中度无变化趋势;无技术替代/政策变化/大客户自供的近期催化。

**弱(rent 易侵蚀)**:大客户开始自研/自供;集采/反垄断/限价有近期推进;同业产能加速扩张(顶部信号);关键牌照/专利即将到期。

## A股 Worked Example:某组装/集成环节在热门题材里

```
看似: 收入大涨,"X 题材受益股"
实际:
  - 大客户截留(下游品牌/平台买方议价): ~30%
  - 上游卡脖子截留(核心芯片/材料拿走大头): ~50%
  - 同业竞争(多家竞标压价): ~10%
  → Rent capture: ~10%

结论: 即使在受益链上,该公司实质是"被挤压者"——产业利好大部分被上游和大客户截留,
公司层面 rent 仅约 10%。这种公司即使题材持续,盈利贡献也有限。
对应题材链「蹭概念/伪受益」与「真受益」的核心分水岭。
```
