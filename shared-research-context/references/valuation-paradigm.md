# A股估值范式(资产类型 → 估值方法)

> **强制纪律**:估值章节必须按资产类型选估值法——绝不可用单一 PE 评估周期股 / 未盈利成长股 / 银行 / 题材股。
> 不必把所有方法都算,按案例选 1-3 个最相关的深入即可。
> **只在用户明确要求估值时输出**,且严守输出边界(见末尾):不出目标价 / 合理价 / 买卖时点。

> **A股 与美股的根本不同**(移植自美股范式时已据此重做,非照抄):
> A股 估值更依赖 **历史分位 + 政策 + 题材阶段 + 股息率**,DCF 与绝对倍数可信度低于美股;
> 板块制度(主板/创业板/科创板/北交所)、限售解禁减持、AH 溢价、集采/中特估等政策项,都是美股没有、A股 必看的维度。

---

## 一、按 A股 资产类型选估值法

### 核心资产 / 白马(高 ROE、稳定复利)

- **首选**:PE-TTM 历史分位 + 股息率 + ROE 趋势 + PEG;自身历史 PE band
- **次选**:DCF(保守增长,A股 可信度有限,只作辅助)
- **禁用**:简单历史均值回归(真白马不回归到行业均值);单纯 PB
- **A股 特殊**:白马的"确定性溢价"随市场风格切换波动大(抱团-瓦解),高分位 ≠ 必跌,但要看 ROE 是否见顶、风格是否切换。真降级信号:ROE 下行 + 再投资回报走低 + 护城河侵蚀。

### 周期 / 资源股

- **首选**:PB + 历史 PB 分位 + 产能利用率/景气位置;归一化(mid-cycle)盈利
- **行业特殊**:煤炭/钢铁/有色/化工看 PB + 商品价格 + 吨毛利 + 库存;航运看 EV/船队 + 运价;养殖看 头均盈利 + 猪周期位置
- **禁用**:trailing PE(**A股 周期股最大陷阱**:顶部 PE 5x 看似便宜实为卖点,底部 PE 50x/亏损看似贵实为买点);PEG
- **A股 特殊**:周期底部 PE 极高甚至为负,**不是降级信号**;PB < 1 + 行业资本开支/折旧 < 1 常是底部信号。

### 题材 / 成长股(渗透率提升、远期空间)⭐

- **首选**:PS + 渗透率/远期空间贴现(市梦率);已盈利用 PEG / EV/EBITDA × 增速;多业务用分部估值(SOTP)
- **科创板未盈利**:PS、管线 NPV(创新药)、产能/订单(制造),**不用 PE**
- **禁用**:trailing PE(早期亏损或微利失真);单纯 PS 不结合增速与盈利路径
- **A股 特殊(最重要)**:题材股估值合理性**必须结合 theme_stage 与拥挤度**(见 [theme-chain](../../theme-chain-context/SKILL.md)):
  - 早期 + 真受益:可给远期空间想象(高 PS 可能合理)
  - 晚期/已透支 + 拥挤度高:高估值 = 真危险(市梦率 priced-in,见光死)
  - 蹭概念:不给题材估值溢价,回归主业估值

### 金融股(A股 口径,非美式)

- **银行**:PB + 不良率/拨备覆盖 + 股息率 + ROE(**不用美式 ROTCE/CET1 那套**);破净是常态,看资产质量与分红持续性
- **券商**:PB + β(强周期,跟行情成交);不用 PE
- **保险**:P/EV(内含价值)+ 新业务价值 NBV 增速 + 综合成本率(财险);不用单纯 PE
- **禁用**:单纯 PE 评金融股

### 红利 / 价值股(含中特估)

- **首选**:股息率 + 派息率持续性 + PB + 自由现金流
- **A股 特殊**:中特估——低估值高分红国企(银行/煤炭/电力/运营商/建筑),估值修复看政策(国资市值管理考核)+ 股息确定性,而非成长

### 困境反转 / ST

- **首选**:下行情景隐含价值、PB(清算/重置)、扭亏路径的可观测信号
- **A股 特殊**:注册制后**壳价值逻辑已大幅弱化**,退市常态化——不要再给"保壳/重组"高溢价;看主业是否真实反转 + 退市风险

### 事件 / 重组驱动

- **首选**:场景赔率(上行×概率 − 下行×概率)、事件前后隐含估值差
- **A股 特殊**:重组/资产注入/借壳预期不确定性高(停牌、问询函、监管审批、政策口径变化),概率要保守;不用传统 DCF

## 二、A股 独有估值维度(US 无,必看)

1. **板块制度差异**:主板(偏价值/红利)、创业板(成长溢价)、科创板(允许未盈利,用 PS/管线/产能)、北交所(流动性折价)——同样业绩,板块不同估值锚不同。
2. **历史分位法**(A股 最常用的锚):PE-TTM / PB 在**自身近 5-10 年**和**所属行业**的分位,比绝对倍数更实用;但要剔除一次性损益用扣非 PE。
3. **股息率 / 中特估**:高股息策略与国企估值修复,看股息率 vs 无风险利率利差 + 分红持续性。
4. **政策估值项**:集采杀医药估值、中特估抬国企、牌照/补贴/限价对估值的系统性压制或抬升——A股 估值必须显式考虑政策方向。
5. **供给面压制**:限售解禁、定增、大股东减持(减持新规)、再融资节奏——A股 特有的估值供给扰动,临近大额解禁/减持时估值有压制。
6. **AH 溢价**:A/H 两地上市的折溢价(AH 溢价指数)作为 A股 估值是否偏贵的参照。
7. **题材市梦率 × theme_stage**:见上,题材估值合理性与题材阶段强绑定。

## 三、多方法交叉验证(A股 football field)

不让单一方法独占判断,用多方法交叉验证**当前价格隐含假设是否合理**,不输出"合理价值区间/目标价"。

- 核心资产:PE 分位 + 股息率 + DCF + 同业可比
- 周期资源:PB 分位 + 归一化 PE + 重置价值 + 商品价格敏感性
- 题材成长:PS + 渗透率贴现 + SOTP + (结合 theme_stage)

**输出边界**:
- ✅ 可以说"多方法共同指向当前估值对增速/利润率的容错率很低"
- ✅ 可以说"PE 已处历史 90 分位,且卖方开始下修盈利"
- ❌ 不输出"合理价值区间为 X-Y 元""目标价 X 元"

---

## 四、估值水位的资产类型解读

- 核心资产长期处于自身高分位 = 可能是常态(确定性溢价),不应单凭高分位降级
- 周期股底部倍数极高/为负 = 不应作为拒绝信号
- 仅在 **题材股 + 拥挤度高 + 已透支/卖方下修** 三者叠加时,高估值才是真危险
- 红利股低 PB 高股息 = 可能是价值而非陷阱,看分红持续性与资产质量

## 五、估值范式选错的典型失败(A股)

| 错误 | 后果 |
|---|---|
| 用 trailing PE 评周期股顶部 | PE 5x 觉得便宜 → 买在景气最高点 |
| 用 trailing PE 评周期股底部 | PE 50x/亏损觉得贵 → 错过最佳买点 |
| 用 PE 评未盈利科创股 | 亏损显示 N/A → 直接跳过,漏掉成长 |
| 用历史均值评核心资产 | 永远"高估" → 错过长期复利 |
| 用美式 ROTCE/PE 评 A股 银行 | 不看不良/拨备/股息 → 误判 |
| 给已透支题材股按"远期空间"估值 | 市梦率已 priced-in → 买在见光死前 |
| 给 ST/困境股按旧壳价值溢价 | 注册制退市常态化 → 踩雷 |

## 六、Hard Rules

### 方法选择

- ❌ 用 trailing PE 评周期 / 未盈利成长 / 银行 / 题材股
- ❌ 用历史均值评核心资产白马
- ❌ 用单一估值法评多业务公司(用 SOTP)
- ❌ 照搬美式 ROTCE/CET1/Rule40/Options-implied 等 A股 不适用口径
- ✅ 按资产类型选方法;题材股估值必须结合 theme_stage 与拥挤度
- ✅ A股 优先用历史分位 + 股息 + 政策 + 题材阶段;DCF/绝对倍数只作辅助
- ✅ 选 1-2 个最相关方法深入,不必全算

### 估值输出边界(防"目标价化",A股 散户化更要严)

**允许输出**(分析判断):
- ✅ 当前价格隐含什么假设(reverse 反推:倒推隐含增速/利润率/份额)
- ✅ 判断:高估 / 合理 / 低估(必须给充分理由)
- ✅ 关键敏感性:增速 / 利润率 / 倍数 / 折现率各变化 ±X% 时估值变化
- ✅ 反证条件:什么数据出现会改变这个判断
- ✅ 乐观 / 中性 / 悲观情景:只给**上下行幅度百分比**

**禁止输出**(actionable signal):
- ❌ "对应股价 X 元""合理价 X""合理区间 X-Y""目标价 X"
- ❌ "建议买入价 / 卖出价"
- ❌ "现在应该买入 / 卖出 / 持有"
- ❌ 情景**股价数字**(即使标"非目标价",散户仍读成目标价)——只允许情景方向 + 估值压力 + 上下行百分比
