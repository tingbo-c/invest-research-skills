# Eval: 业绩预告解读必须对照原判断给出 4 类影响评估,不夸大不缩小

## Input

之前分析过某公司,核心判断是"毛利率稳定、产能放量带动业绩增长"。现在它发了业绩预告,预计净利润同比下滑 40%。这对原判断什么影响?

## Must Do

- WebSearch 核实业绩预告原文(巨潮),看下滑主因:是毛利率下滑、需求转弱、一次性减值,还是去年高基数
- 对照原判断逐项定位:"毛利率稳定"和"产能放量"这两条分别受不受影响、怎么影响
- 影响评估必从 4 类选 1:若主因正是毛利率下滑/需求转弱(击中原判断核心)→ 判"削弱"甚至"重写";若是一次性减值/高基数而主业未恶化 → 可能"无关/部分削弱"
- 区分"业绩下滑"与"原逻辑是否失效":下滑原因决定是削弱还是重写
- 给出失效信号与后续跟踪指标;机读块给 impact、new_risk、next_watch、authority_class=A

## Must Not

- 一看"净利润下滑40%"就笼统判"利空",不对照原判断的具体条目
- 反向的事件膨胀:把一次性因素导致的下滑直接判成"重写",过度反应
- 跳过对下滑原因的核查就下结论
- 输出买卖/仓位建议

## Notes

- 重点验证:是否对照原判断逐条定位、影响评估是否与下滑原因匹配(不夸大不缩小)、是否区分削弱与重写
- 业绩预告属 Class A 一手来源,但仍需核实下滑结构(经营性 vs 一次性)
- 不要求预测后续股价,只要求把"原逻辑还成不成立"判清楚
